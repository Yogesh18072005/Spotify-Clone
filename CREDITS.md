## Technology and third-party services

Melody is built with and uses the following open-source projects and services:

- [React](https://react.dev/) and [React DOM](https://react.dev/) — user interface
- [Vite](https://vite.dev/) — frontend development and build tooling
- [Node.js](https://nodejs.org/) and [Express](https://expressjs.com/) — backend runtime and API
- [MongoDB](https://www.mongodb.com/) and [Mongoose](https://mongoosejs.com/) — database and object modelling
- [Lucide](https://lucide.dev/) / [Lucide React](https://lucide.dev/guide/packages/lucide-react) — interface icons
- [Audius](https://audius.org/) — music discovery and streaming catalogue
- [JioSaavn](https://www.jiosaavn.com/) — external destination for Indian music browsing
